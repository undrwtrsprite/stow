# Historical versions

All 18 original stow JARs available in the version archive have been preserved, from **0.1.0+mc26.3** through **0.5.10+mc26.3**. Download them from [GitHub Releases](https://github.com/undrwtrsprite/stow/releases). The Git branch [codex/archived-releases](https://github.com/undrwtrsprite/stow/tree/codex/archived-releases) contains every JAR, the original 0.4.0 source ZIP, a version manifest and SHA-256 checksums. Only versions named stow are included.

Each JAR's embedded Fabric mod ID/version and filename were checked. The original files are unchanged. These are recovery commits and releases: their dates record the import and publication, not the original development dates. Import verification checks preservation and metadata; it does not claim new gameplay testing of the older builds.

## Available source

| Version | Source |
| --- | --- |
| 0.4.0+mc26.3 | [Original recovered source](https://github.com/undrwtrsprite/stow/tree/v0.4.0%2Bmc26.3), with all 75 files preserved unchanged. The original ZIP is attached to its release and retained in the archive branch. |
| 0.5.10+mc26.3 | [Published source tag](https://github.com/undrwtrsprite/stow/tree/v0.5.10%2Bmc26.3), pointing to commit `d23eb958b53521cb0cd13511d5a68a48ce6d93ef`, including the published Loom build configuration correction. |
| Other versions | Original JARs only. Their original source is not currently available. |

Tags starting with **binary-v** point to the binary archive branch. GitHub's automatically generated source downloads for these tags contain that archive tree, not an original source snapshot for the named version. Source tags for 0.4.0 and 0.5.10 use **v**.

The original 0.4.0 source still pins Loom 1.17.0. It is preserved as received and has not been rebuilt or repaired during this import. For current build instructions, use [DEVELOPMENT.md](DEVELOPMENT.md).

No other original source archives were available at import time. No historical source was reconstructed from JARs, and no intermediate source snapshots or development dates were invented.

stow began as a project for friends, with substantial AI assistance. Original licensing and Mouse Wheelie attribution are retained in the archived files; see [LICENSE](../LICENSE), [NOTICE](../NOTICE) and the [README](../README.md).
